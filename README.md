# Airbnb Data Analysis Dashboard
🚀 Click here to view the Live Dashboard
An interactive dashboard built using Python, Pandas, Streamlit, and Plotly to analyze Airbnb listing data.

## Features
- Price comparison across room types
- Hotel room price analysis across neighbourhoods
- Number of listings across neighbourhoods
- Interactive filters
- KPI summary cards
- Geographical Airbnb listing map
- Dataset preview and CSV download

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly

## Run Locally

Install dependencies:

`pip install -r requirements.txt`

Run the application:

`streamlit run app.py`
